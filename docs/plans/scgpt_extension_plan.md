# scGPT against CLR-NS, tcaCLR and tcaCLR2 on more human datasets: pre-specified plan (21 Nov 2026)

*Written before any new scGPT network, tcaCLR or tcaCLR2 single-cell score exists. Pre-specified, not registered externally. Nothing here has been run; counts below come from file metadata and from the earlier results documents.*

## 1. Question and status of the evidence
Is a training-free CLR-family score at least as good as scGPT whole-human at recovering known regulator-target (and complex) relations from single-cell expression, and is that more than a two-dataset impression? Existing evidence (`docs/scfm_scoring.md` sections 6, 7, 11) is descriptive: CLR-NS minus scGPT attention is +0.37 log2 (range +0.18 to +0.57, n = 2: hESC, hHep), minus token-embedding cosine -0.78, minus hidden-state cosine -0.29; the K562 stratum (5 control subsamples, one block) points the same way (attention +0.63, token cosine -0.31, hidden cosine +0.25, pooled over three truths). **Disclosure:** those numbers are known to us. Making scGPT attention the primary readout is the scGPT readout fixed in the 21 Oct preregistration; it was not re-chosen after seeing the numbers, but "best readout" is now also tested (S1). A premise correction: the earlier scFM arms scored TF truths (BEELINE ChIP and STRING, DoRothEA A-B, CollecTRI, knockdown-response), **not complexes**; complexes are new to this comparison.

## 2. Model, readouts, datasets, truths
- **Model:** scGPT whole-human only (`~/scfm_models/scgpt_human`, SHA-256 in the preregistration change log; extractor `analysis/scfm_extract_scgpt.py`, unchanged settings: last layer, 51 value bins, `<cls>` removed, binning seed 20261021). No fine-tuning, no controls. scPRINT is not rerun.
- **Readouts (as before):** attention (last layer, head mean, S = Aᵀ, preregistered main readout); token-embedding cosine (data-free); hidden-state cosine. `tok_cos_ln` stays exploratory.
- **Methods compared:** CLR-NS (`ns_clr`), tcaCLR (the BEELINE-scoreboard definition: CLR-NS operator, keff 10, cap 50, lazy 0.5, t = 9, `sk_a3r`), tcaCLR2 (t2 from the permuted-data edge rule of `docs/plans/tcaclr2_definition.md`, recomputed on each G∩ matrix, label-free). |r| and CLR as references. All on the scGPT-covered genes and the same cells.
- **Datasets (blocks):** hESC and hHep (BEELINE cases, TFs+500 and TFs+1000, all cells, existing extraction); K562 (existing, 5 subsamples of 1,024 controls); and new: HepG2 and, if downloaded, Jurkat and RPE1, built exactly as K562 (non-targeting controls, 5 seeded subsamples of 1,024, seeds 1-5, raw UMI; genes = CollecTRI TFs with at least 10 targets detected in at least 5% of controls plus the 1,000 most variable detected genes; CollecTRI read only for regulon sizes). A dataset enters if it has at least 512 controls (fewer than 1,024: all cells, one subsample).
- **Truths, primary:** DoRothEA A-B and CollecTRI (directed, TF-node `score_truth`), identical for all blocks (hESC and hHep newly scored on them). **Secondary (descriptive):** BEELINE primary truths for hESC/hHep (already seen); knockdown-response modules where a bulk file exists (K562, RPE1 local, HepG2 rebuilt; not Jurkat); **complex stratum:** Complex Portal human (builder `analysis/tcaclr_confirm/build_human_truth.R`), pooled co-membership AUPR, undirected, G∩. Truth spent on other data: DoRothEA/CollecTRI on K562, Complex Portal on HepG2 pseudobulk; the single-cell inputs here are new.

## 3. Statistics
d_i = per dataset, mean over subsamples (or cases) and the two primary truths of log2(AUPR ratio of the CLR-family method / that of the scGPT readout); positive favours the CLR-family method. Margin delta = 0.15 log2; exact Wilcoxon-Hodges-Lehmann interval [L, U] and decision table exactly as `docs/preregistration_scfm.md` (NI if L > -delta; superior if L > 0; tie if L > -delta and U < delta; scGPT wins if U < 0; else inconclusive). Intervals by n: n = 6, L and U are the 3rd and 19th of 21 Walsh averages (coverage 90.6%, smallest one-sided p 1/64 = 0.0156); n = 5, L = min d_i, U = max Walsh average (93.75%, p 1/32 = 0.031); **n = 4 (hESC, hHep, K562, HepG2) cannot decide anything** (smallest p 0.0625), so the downloads below are needed for any decision. Simulated probability of showing NI (n = 6): true difference +0.2, SD 0.15: 1.00; SD 0.30: 0.76; true difference 0: 0.65 and 0.26. Heterogeneity across datasets, not n alone, will decide.
- **Primary P1:** CLR-NS vs scGPT attention, n blocks. One interval, no multiplicity; superiority read next (no alpha spent).
- **Key secondaries, Holm 0.05 over two, confirmatory only if P1 shows NI:** S1 CLR-NS vs the best of the three scGPT readouts per dataset (robust NI, chosen on the truths, optimistic for scGPT); S2 tcaCLR vs scGPT attention (NI). With n = 6 both are attainable (0.0156 below 0.025); **with n = 5 they are not (0.031 above 0.025) and become descriptive.**
- **Descriptive, intervals but no claims:** every other readout x method contrast (including token and hidden cosine, which are expected to beat CLR-NS on hESC, hHep and K562, so S1 is expected to fail), per truth, per dataset, fresh-only blocks (HepG2, Jurkat, RPE1; no interval at n <= 3), leave-one-dataset-out, KD-response, BEELINE truths, complex stratum, regulator bootstrap within dataset (B = 1,000, as K562).
- **tcaCLR2 is exploratory.** It is the separately named, data-derived-depth variant; it enters no test, no Holm family and no decision label; it is shown as a column with d_i, t2 and edge per matrix. Allowed wording: designed to adapt to the dataset, equivalent to tcaCLR within tolerance on spent truths; not allowed: that it works or works better on a new dataset (it failed its reading on HepG2 pseudobulk, ratio 0.919).
- Floor caveat: scGPT attention AUPR ratios were about 1.0-1.2; NI against a near-null comparator is weak evidence and is said so with the AUPR ratios beside every d_i.

## 4. Leakage audit for scGPT pretraining
Known: scGPT whole-human is "33 million normal human cells" from CELLxGENE, checkpoint dated June 2023; the census snapshot is not stated. E9 (`results/scfm_step2/leakage_audit.csv`) checked all three LTS releases by accession, BioProject, DOI and author-year: hESC GSE75748, hHep GSE81252 and the Replogle K562 deposit (PRJNA831566) are classified **out, moderate confidence**; residual limit: reuse inside an atlas that does not cite the study. To do before extraction (metadata only, `scfm_step2_leakage.py` pattern): add rows for HepG2 and Jurkat (Nadig et al. 2025, GSE264667, released 2024, after the checkpoint, so out by date) and RPE1 (Replogle 2022, PRJNA831566, covered by the K562 search but never listed separately: add the row; RPE1 is non-cancer, so the normal-only filter does not exclude it). Cell-type exposure (hepatocytes, T cells) in the corpus is not dataset leakage and cannot be excluded. Leaked-dataset sensitivity analysis: expected empty; if a row turns "in", report with and without it.
